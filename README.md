# HumanGeography_Summer25
**GEOG 102** *(Human Geography)* course notebooks used at Santa Barbara City College (SBCC), Summer 2025. This includes 4 interactive jupyter notebook assignments. 
The notebooks follow the same format used in **CS/MATH 118** *(Data Science for All)*, a foundation in Data Science course modeled after UC Berkeley’s Data 8 course.
